# Hub de Marco Portugal

Sitio estático con Astro. Costo: solo el dominio.

## Probar en tu computadora
    npm install
    npm run dev      # abre http://localhost:4321

## Estructura
- `src/config.ts`: nombre, frase principal y enlace de LinkedIn
- `src/content/articulos/`: un archivo .md por artículo
- `src/pages/`: Inicio, Artículos, Sobre mí, Sesiones
- `.pages.yml`: formulario de Pages CMS para que Marco publique

## Publicar un artículo (Marco)
Entrar a app.pagescms.org con GitHub, abrir "Artículos", crear uno nuevo, guardar.
La web se actualiza sola en uno o dos minutos.
